# comphero-mod

Adds a **"Cut last 5s"** button to CompHero's Trim view header (left of Export). It cuts the last 5 seconds off every clip except the last one.

## Use
```
npm install
node install.mjs            # apply the mod (close CompHero first)
node install.mjs --restore  # put the original files back
```
Re-run `install.mjs` after CompHero auto-updates.
